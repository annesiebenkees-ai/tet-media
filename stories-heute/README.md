# Stories HEUTE

Ablage des TET-Tools: `stories-heute/<YYYY-MM-DD>/` mit fertigem Video (Untertitel eingebrannt) und `auftrag.json`.
Jeder Push hier startet die Cloud-Routine `tet-story-heute-posten`, die offene Eintraege (status bereit, ohne gepostet) sofort ueber Metricool als Instagram-Story postet.
